## 📘 Chapter 04 - 프로젝트 초기 구조 세팅

이번 과제에서는 Node.js 프로젝트의 **기본 폴더 구조**을 실습했습니다.

### 🗂️ 디렉토리 구조
`src` 폴더 내에 계층별 구조를 생성했습니다.

```
src/
├── controllers/   # Controller 코드
├── dtos/          # DTO (Data Transfer Object)
├── repositories/  # 데이터 조작 로직
├── services/      # 비즈니스 로직
└── index.js       # 앱 진입점
```
